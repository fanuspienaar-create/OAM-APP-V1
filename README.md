# OAM Studio v11 — Invoice & Quote Format

Updated from v10 while keeping the existing OAM Studio UI.

- Invoice/quote PDF geometry follows the supplied Fanus Pienaar A4 reference.
- Logo is rendered proportionally inside the reference artwork area.
- Fixed table column positions and text fitting to prevent text crossing column lines.
- Banking details can be edited per quote/invoice and included/excluded from the PDF.
- Settings also stores default Bank Name, Account Name, Account Number, Account Type and Branch Code.
- Quote and invoice documents keep their own banking details so older documents remain stable when settings change.
