# OAM Studio v9

OAM Studio — One Stop Artist Marketing Studio.

## Invoice & Quote PDF
This version includes a self-contained browser PDF generator. No paid PDF service or API key is required.

Create a Quote or Invoice, save it, then click **Download PDF**. The output is an A4 PDF based on the supplied Fanus Pienaar invoice reference.

The layout includes:
- OAM/artist logo at top left
- INVOICE or QUOTE heading
- Number, reference, date, due/valid date and page
- FROM / TO
- VAT numbers
- Postal and physical address sections
- Salesperson, Job, Payment Terms and Date of Event
- Qty / Description / Unit Price / Line Total table with blank rows
- Subtotal, Sales Tax and Total
- Bank/payment details
- Thank-you footer

Business and client details are taken from OAM Studio settings and the document form.


## Invoice/Quote PDF v10
The PDF generator follows the supplied Fanus Pienaar invoice layout: large artwork/logo at upper left, document details at upper right, FROM/TO blocks, job/payment row, 8-row item table, totals and bank details. Saving a quote or invoice also starts a PDF download.
